The **Agents** section lists this machine's chats on the left and the open chat on the right.

## The list

- **+ New chat** with a model menu. A chat row shows its dot (red waiting, pulsing working, yellow open, green done), title, time, model, tag, Auto when on, and the hammer line of what its agent says it is doing ([the board](/embry-wiki/concepts/working-in-parallel/#the-board)).
- A **title filter** over chats and shells. **⋯** or right-click on a row: Rename, Name it from the chat, Tag (Projects, Areas, No tag, New project or area), Close, Delete.
- **All sessions on this machine** below the pinned rows: every other Claude, Grok and Codex session, grouped by folder, with closed-with tags. Click one to adopt it onto the list and open it; ⋯ → Delete from this machine erases it.
- **> Terminal** opens a shell on this machine, listed above the chats, in a real terminal pane.

## The chat

The same chat as the phone: history paged by **Older messages…**, streaming replies, the Allow/Deny card, a composer with **+** for pictures and files (pasted or dropped images are scaled and sent in line), `/` for the skill menu, Enter to send. A microphone button (⌘⇧D, or Ctrl+Shift+D) types what you say into the box; on Apple silicon the first use downloads a speech model onto this Mac, and nothing is sent until you send it. If the microphone is off, the notice has **Open Microphone settings**, which opens Privacy & Security → Microphone on a Mac and Privacy & security → Microphone on Windows. If a recording cannot be read, the notice says to try again. The up and down arrows recall what you sent. The header has the tag chip, the model menu, the Ask/Auto toggle, the effort menu and ⋯. New chats start in Auto. Settings can make them ask first again.

A picture the agent shows appears in line. Close chat ends it; the row drops into the All sessions group.

## Sessions started elsewhere

A chat is one session, whichever screen you use. Start it on the phone, continue it here, pick it up in a terminal with the command the chat's ⋯ menu offers (**Continue in Terminal** seeds the shell with the resume command and waits for Return). While a terminal or Obsidian is driving a chat, the apps show **At the desk** and hold Send.
