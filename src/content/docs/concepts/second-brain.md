The second brain is a folder of plain Markdown notes on your computer. An Obsidian vault works best, but any folder will do. HomeADE and FieldADE never move your notes anywhere else. There is no account.

## Projects and areas

A **project** is a folder of notes about one piece of work with an end: a build, a move, a tax year. An **area** is the same for something ongoing: a client, a house, a team, your health. Each has a roll-up note with the same name as the folder. The roll-up holds a one-line **phase**, the **next** action, an optional **blocked** line, and the date it was last touched. Those four lines show word for word on the Today screen, so if the dashboard is wrong, the note is wrong.

Notes filed beside the roll-up are the project's record: the mail you filed, the scan, the decision from last week.

## Ingest

Ingest is the inbox of the notes. Mail, texts, a pasted note, a scanned document, a photo from the share sheet, a loose audio or video file all land there. For each item the app proposes a home (which project or area) and what the note should say. You confirm, and it is filed. Nothing is filed unseen.

## Why the notes are the memory

When you start a chat on a project, the agent reads that folder first. You do not paste the brief again, and you are not trusting a hidden memory inside a chat app. Every item you file is context for every later chat on that project. On day one the agent asks you questions. A few months in, it already has the answers, because you filed them once.

You can always open a note and see exactly what the agent is working from. Closed chats stay searchable too, with their titles, tags and models, and a tagged chat leaves a one-line summary under its project when you close it.

## Private notes

A note tagged `#private` is never shown in the apps' note reader, never sent to an agent by the Ingest tools, and never summarized. A scanned document that holds a Social Security number, a card number or an ID is flagged before its text enters the folder, and you file it into a fenced folder outside the vault.
