Embry Development makes two products that work as one system, and two stand-alone apps.

## The system

**HomeADE** runs on your computer. It is the desk where your agents work. It keeps a folder of plain notes, the second brain, and files what comes in (mail, scans, pasted notes, loose files) as notes under a project or an area. Every chat you start on a project reads that folder first. HomeADE runs Claude Code, Codex and Grok, the same command-line tools you would open in a terminal, and lists every chat, skill, rule and model on the machine. It runs on its own; the phone is optional.

**FieldADE** is the iPhone app for HomeADE. From the phone you see what is due, read mail and texts, file an item with a swipe, and run the same chats. A file edit or a command waits until you allow it on the phone. It can also run alone, with a notes folder on the phone and your own API key.

## The stand-alone apps

**[Kingdom Guide](/embry-wiki/kingdom-guide/)** plans a day at Magic Kingdom on an iPhone: rides in walking order, posted waits, Disability Access Service return times.

**[LightScan](/embry-wiki/lightscan/)** is a custom build for a foundation repair company: the estimator walks the house and the phone draws the floor plan and a heat map of where the floor sags. It is not a public download.

## A website

## What this wiki is not

It documents what the products do and how to use them. It does not describe the code, the servers behind the relay, or anything a user cannot see. The [privacy policy](https://embry.dev/fieldade/privacy) says what leaves your devices.
